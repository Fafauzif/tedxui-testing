# Letters to Grow

**Still, We Grow.** A standalone letter collection for TEDxUniversitasIndonesia 2027. Open the site and read a letter. Share a line as a Story, Square or Portrait PNG. Write and publish a letter for the next reader.

```sh
npm ci
npm run build
npm start
```

Open http://localhost:4173. Node.js 22.12 or later is required. The local server runs against isolated persistent PostgreSQL and includes the 12 original editorial letters. The included `dist/` folder is a prebuilt frontend if you want to use `npm ci` followed by `npm start`.

# Project context

Letters to Grow is the standalone English-language reader, writer and Story sharing site for TEDxUniversitasIndonesia 2027 and Still, We Grow.

The approved implementation handoff supersedes the source snapshot's mood picker and draft-only writer. Starting at the root opens a visible letter. Existing `/?letter=<id>` permalinks retain all 12 fictional editorial records and their attribution. New letters join the same rotation following explicit publication. Staff manage visibility through Supabase Dashboard.

The source baseline is GitHub commit `a1350e241afe77a2328d127ff84089ca3b3e70ba`, confirmed against repository HEAD before implementation. The release was developed in an isolated local checkout and the production environment awaits approval.
